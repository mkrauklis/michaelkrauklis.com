Matrix Matrix

Attention reshapes words by "multiplying by a matrix." Tonus's neural network is nothing but matrices, layer after layer. This page is the thing itself, on its own, worked by hand — what a matrix actually is, a few things it can stand for, and exactly what happens when you multiply two of them together, from the smallest case up to two matrices that don't even match in shape.

01 — what is a matrix

Just a grid of numbers

A matrix is a rectangular grid of numbers, arranged in rows and columns. That's the whole definition — nothing about it is more mysterious than a spreadsheet with the row and column headers stripped off. A matrix's size is always written rows × columns, in that order — a common early mix-up is flipping them, so it's worth saying out loud: rows first, then columns, every time. 03 — multiplying two matrices

Row, times column, added up

Here's the entire rule: to find the number that goes in row i, column j of the answer, take row i of the first matrix and column j of the second matrix — two equal-length lists of numbers — multiply them together position by position, and add up the results. That's a dot product, the exact same operation Attention uses to compare two words. Do that once for every row/column pairing, and you've filled in the whole answer. Click any cell in C below to see exactly which row and column made it.

Start small: 2×2 times 2×2

The same idea, just bigger: 4×4 times 4×4

Nothing about the rule changed — every cell of the answer is still one row dotted with one column. There are just more numbers to multiply and add per cell (4 terms instead of 2) and more cells to fill (16 instead of 4).

Different shapes: 1×2 times 2×4

Square matrices can hide a real requirement: the first matrix's number of columns has to match the second matrix's number of rows — here, 2 and 2. Every row of A and every column of B still has to be the same length for the dot product to even make sense; that shared length (2) disappears from the answer's own shape, which ends up 1 row × 4 columns — one row from A, but every column from B, each one getting its own dot product against A's single row.

05 — why this matters

This is the one operation everything else here runs on

Neural networks (see Tonus) are, underneath the training and the jargon, layers of matrices multiplied one after another — every "neuron" is just one row of a dot product.

Attention (see Attention) reshapes every word's fingerprint into a Query, a Key, and a Value using exactly the multiplication from Stage 3 — three different matrices applied to the same starting numbers.

Computer graphics and games move, rotate, and scale every 3D model you've ever seen on screen using the same transformation idea from Stage 2 — just with bigger matrices, and many more points per shape.

Image filters (blur, sharpen, edge-detection) work by multiplying a small matrix across every patch of pixels in a photo — the same "picture is a matrix" idea from Stage 2, with a second matrix doing the reshaping.

A design for anyone who's ever gotten this wrong

How this actually works — the precise version

For matrix A (size m×k) and matrix B (size k×n), the product C = AB (size m×n) is defined entry by entry:

C[i][j] = Σt=1..k A[i][t] × B[t][j]

Computing the whole matrix this way takes m × n cells, each one costing k multiplications and k−1 additions — for two square n×n matrices, that's O(n³) total, the naive algorithm every intro course teaches first. It's not the fastest one known: Strassen's algorithm (1969) does better by recombining the multiplications themselves, and faster algorithms have been found since — see "Learn more" below. Every demo on this page uses the plain O(n³) definition above; the answer is identical either way, just computed with more or fewer multiplications along the way.

Matrix multiplication is also not commutative: in general, AB ≠ BA — swap the order and you can get a completely different answer, or an operation that isn't even defined anymore (an m×k matrix times a k×n one works; flip the order and it only works if n happens to equal m too). Try it on the 2×2 demo in Stage 3: swap which grid holds which numbers and watch the answer change.
